# Lessons

## 2026-08-24 — Independence means skill-only installation

- Do not treat “pipeline-independent” as permission for generic skills to require `sports_ds` core.
- The acceptance test is a user who installs only one or more skills: the guidance and bundled helpers must still work.
- Generic skills should consume user-owned, documented artifacts and public dependencies.
- Centralize all optional `sports_ds` package, loader, CLI, and pipeline integration in one explicitly routed bridge skill.
