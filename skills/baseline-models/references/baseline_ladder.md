# Baseline Ladder

1. **Constant / mean** — floor.
2. **Single domain factor** — home, rest, or rating diff.
3. **Small logistic/linear set** — home + form/rating diffs.
4. **Only then ML.**

## Promotion

Higher complexity must improve walk-forward primary metric on multiple folds.

## Demotion

If a simpler baseline matches the complex model, keep the simpler baseline.
