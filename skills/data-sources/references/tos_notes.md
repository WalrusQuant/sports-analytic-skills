# Terms and attribution

- sportsleader-data is a convenience copy of public game, box, roster, injury, transaction, lineup, depth-chart, and weather rows.
- Attribute game data to ESPN and to any other source named on that dataset. Attribute the files to https://github.com/WalrusQuant/sportsleader-data
- sportsleader-data is not affiliated with ESPN, those other sources, or the leagues.
- No other license is granted for the underlying data. It stays under the terms of its source.
- Do not claim the Parquet files include ratings, forecasts, or betting lines.
- Snapshot the manifest `sha256` with the file. Do not silently replace a snapshot an experiment cited.
- Prefer the published Parquet or the sports-leader connector over scraping the upstream site.
- Cache and redistribute only within the source terms the user has accepted.
