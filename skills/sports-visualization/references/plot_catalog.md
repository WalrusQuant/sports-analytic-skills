# Sports Plot Catalog

| Plot | Use | Needs |
|---|---|---|
| Coverage timeline | seasons/weeks present | schedule/panel |
| Target histogram | margin/score distribution | outcome col |
| Home advantage bar | home win rate by season | home rows |
| Form line | rolling/EWMA trajectory | shifted form |
| Calibration curve | prob reliability | p, y |
| Residual scatter | margin model fit | y, yhat |
| Rating trajectory | Elo/power over time | as-of ratings |
| Walk-forward metric table | model vs baseline | fold metrics |

Every key figure: period, n, metric definition, baseline when comparing.
