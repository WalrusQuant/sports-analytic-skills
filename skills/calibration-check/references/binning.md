# Binning for Calibration

## Equal-width
Default 10 bins on [0,1]. Good when probs spread out.

## Quantile
Use when mass clumps near 0.5. Each bin gets similar n.

## Tails
Always inspect 0–0.2 and 0.8–1.0 separately when quoting strong favorites/dogs.

## Rules
- Report n per bin
- Do not interpret empty bins
- Pre-declare binning before looking at curves when possible
