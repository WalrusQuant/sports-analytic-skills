# Interpretation Methods (Sports)

## Coefficients

For logistic win models, report odds ratios with CIs. State feature units.

## Importances

Use as triage, not proof. Check stability across seasons.

## Slices

Prefer pre-declared sports segments: season, home/away, week phase, prob tails.

## Ablation

Drop a feature group, re-run walk-forward, compare primary metric.
