What you get

A jumpstart for serious sports modeling

Not a black-box picks engine. Operator manuals your agent can follow — EDA through honest reporting — on data you own.

01

Install into any agent

Works with Claude Code, Cursor, and other agents that support the Agent Skills standard. One command. No clone required for skill-only use.

02

Point it at your data

Skills consume CSV, Parquet, or JSON you already have. Each skill documents the grain and fields it needs instead of inventing hidden pipelines.

03

Time-safe by default

Decision-time legality, walk-forward validation, leakage audits, and calibration checks are first-class — not afterthoughts bolted on at the end.

04

Baselines before complexity

Constant rates, home-field, and simple statistical baselines come before fancy models. If you cannot beat dumb, you do not ship smart.

05

Public data paths

Skills for nflverse, sportsdataverse, and pybaseball when you need data. Optional sports_ds toolkit if you want prebuilt loaders and reference pipelines.

06

Honest reporting

Model cards, experiment logs, miss analysis, sample sizes, uncertainty, and limits. The pack is built to kill sloppy analytics, not enable it.

What this is / is not

This pack is scaffolding so you can learn the workflow and build your own work. It does not claim betting edge, guaranteed profit, or finished market models.

This is

  • A free jumpstart for sports analytics with agents
  • Operator manuals for EDA, features, models, validation
  • A way to learn leakage, calibration, and honest reporting
  • Optional public-data helpers for NFL, NBA, MLB
  • Yours to fork, extend, and break on your own data

This is not

  • A betting tip service or guaranteed edge engine
  • A black-box model that prints money
  • Custom sport/market build-on-request support
  • A hosted dashboard or pick seller
  • Permission to skip learning how validation works

Get started

One command

No repo clone required for skill-only use. Point the agent at your files and go.

# Interactive install
npx skills add WalrusQuant/sports-analytic-skills

# One skill, non-interactive
npx skills add WalrusQuant/sports-analytic-skills --skill eda-sports -y

# Entire pack for every detected agent
npx skills add WalrusQuant/sports-analytic-skills --all
