# Prior art

Inspiration and standards this project steals shape from.

## Skill systems

- [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) — large scientific skill library + plugin shape
- [Taste / design-taste-frontend](https://github.com/leonxlnx/taste-skill) — judgment dials + anti-slop constraints
- [ds-skills](https://github.com/wenmin-wu/ds-skills) — technique skills distilled from strong notebooks
- [Agent Skills standard](https://agentskills.io/)
- [Agent Plugins](https://agent-plugins.org/)

## Conceptual cousins (not skill packs)

- Model cards / claim cards (honest model reporting)
- Walk-forward and purged CV literature in finance/ML
- Closing line value as a market skill metric in sports betting analysis

## Deliberate differences from K-Dense

- Much smaller core at the start
- Multi-sport modeling engine first; market layer second; no lab/bio/chem surface area
- Documentation seriousness copied early; inventory size not copied early
- Harness is optional and late
- No commercial support / product-funnel positioning
